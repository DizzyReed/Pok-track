# Pokétrack

Pokétrack è un'app Android per seguire in ordine cronologico serie, episodi, film, speciali e miniserie Pokémon.

## Funzioni
- checklist visto/non visto con salvataggio locale
- gruppi serie richiudibili
- avanzamento totale e per serie
- “Continua da qui”
- film e speciali inseriti nella timeline
- aggiornamento online del catalogo
- icona Poké Ball

## AppStudio
Importa questo repository con **GitHub Import**. Una volta importato, apri il progetto e usa la funzione di build APK disponibile in AppStudio.
